# AstraVoid website

A small static website made with plain HTML, CSS, and JavaScript. No framework, build step, or dependencies are required.

## Publish with GitHub Pages

1. Create a repository for the website (for a user site, name it `AstraVo1d.github.io`).
2. Upload `index.html`, `sitemap.xml`, and the `assets` folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. If your published address is not `https://astravo1d.github.io/`, update the canonical URL in `index.html` and the `<loc>` value in `sitemap.xml` to your actual website URL.

## Projects list

The Projects section reads the six most recently updated public repositories from the GitHub API for `AstraVo1d`. It updates automatically when the page is opened. If the API is unavailable, the GitHub profile link remains available.
